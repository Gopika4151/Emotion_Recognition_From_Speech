# Emotion Recognition From Speech

## Project Overview
This project focuses on extracting audio features from speech signals for emotion recognition. Audio processing techniques were used to analyze speech data and extract meaningful features.

## Technologies Used
- Python
- Librosa
- NumPy

## Features
- Audio Signal Processing
- Feature Extraction
- MFCC (Mel Frequency Cepstral Coefficients)
- Speech Analysis

## Project Workflow
1. Load audio data
2. Extract MFCC features
3. Analyze speech characteristics
4. Prepare data for emotion recognition models

## Results
Successfully extracted MFCC features from speech/audio signals for further emotion classification tasks.
